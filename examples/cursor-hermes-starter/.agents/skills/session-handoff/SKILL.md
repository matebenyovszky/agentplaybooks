# Session handoff

End the session with four short headings:

1. **Done** — what landed in the working tree.
2. **Not done** — the next concrete step, not a vague backlog.
3. **Commands** — tests or doctor/sync commands still worth running.
4. **Watch** — files or decisions a future session must not reverse.

Keep it under a screen. No secrets.
