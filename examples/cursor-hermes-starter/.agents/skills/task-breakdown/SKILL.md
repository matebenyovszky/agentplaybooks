# Task breakdown

Turn the request into an ordered checklist:

- Each item is one edit, test, or decision.
- Mark items that need a human (deploy, secrets, product call).
- Stop at a slice that can be reviewed on its own.

Do not expand scope. If something is unclear, ask one question instead of
guessing.
