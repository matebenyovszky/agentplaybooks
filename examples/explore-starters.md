# Explore starter playbooks

`explore-starters.json` is the source of the three generic, first-party examples
linked from Explore. Each includes project instructions, a persona, and one
small skill. They contain no project memory, credentials, or MCP connections.

The canonical hosted links also work from self-hosted installations with their
own databases. Explore does not query a catalog or import these examples at
runtime. The hosted records are owned and published by the AgentPlaybooks
demo/system profile (`00000000-0000-0000-0000-000000000001`), alongside the other
demo playbooks. Keep them out of personal profiles. When revising these sources,
update the existing records using authorized demo-account or database access;
do not create duplicates on each deploy.

Explore's worked scenarios are illustrative customizations of these generic
starters, not live executions or additional data stored in the public examples.

Keep these examples generic and public. Users should make a private copy before
adding project details. The actual agent and its available tools perform the work.
